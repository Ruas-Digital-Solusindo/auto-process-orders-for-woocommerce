Automatically completes WooCommerce orders when customers purchase products at no cost, providing instant access without manual intervention.

== Description ==
Auto-process Orders for WooCommerce automatically completes orders when customers purchase products with a zero price.
This ensures your customers get instant access to their products without waiting for manual order processing.
Perfect for digital products, free downloads, memberships, or any products that don't require manual approval or payment verification.

= Features: =
1. Automatically marks zero-cost orders as "Completed"
2. No manual review or processing needed
3. Instant product access for customers
4. Lightweight and easy to use

= Use Cases: =
1. Free digital downloads
2. Free membership signups
3. Promotional products with 100% discount
4. Just install and activate — no setup required!

== Installation ==
1. Upload plugin to `/wp-content/plugins/` directory
2. Activate plugin from 'Plugins' menu in WordPress
3. Open WooCommerce > 'Free Products Settings' untuk mengatur status otomatis

== Frequently Asked Questions ==
= Does this plugin automatically change the status of all orders? =
No, only orders with a total amount of 0 will be automatically marked as completed.
